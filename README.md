# wg-admin-bash

Интерактивный bash-скрипт для установки и администрирования WireGuard-сервера
(топология Hub-and-Spoke) с меню. Объединяет до 6 ПК в единую VPN-сеть.

> **Статус:** в разработке. Полное техническое задание — локально в `ТЗ.md`
> (в репозиторий не публикуется).

## Целевая среда

- Debian 11/12, Ubuntu 20.04/22.04/24.04 (x86_64, arm64)
- Запуск от root
- bash ≥ 4.4, wireguard, wireguard-tools, qrencode, iptables, systemd, cron

## Установка и запуск

```bash
sudo apt install wireguard wireguard-tools qrencode iptables
sudo bash wg-admin.sh
```

При первом запуске: **[2] Инициализация сервера**, затем **[3] Управление
клиентами → Добавить клиента**. Конфиг клиента сохраняется в
`/etc/wireguard/clients/<name>.conf` (можно вывести QR-кодом).

## Проверка

```bash
bash -n wg-admin.sh
shellcheck wg-admin.sh
```

## Возможности (по разделам меню)

Установка WireGuard, инициализация сервера, управление клиентами (добавление,
срок действия, отключение), мониторинг трафика, сервис, редактирование конфига,
маршрутизация (LAN, site-to-site, split-tunnel), безопасность, бэкап,
обслуживание, диагностика.
